# Technology Stack

이 문서는 프로젝트에서 현재 채택한 핵심 기술과 기준 버전 및 각 기술의 역할을 기록한다.

Python 패키지의 정확한 설치 버전은 `uv.lock`을 기준으로 한다. 외부 도구의 버전은 프로젝트 실행 환경에서 확인한다. 결정 배경과 대안은 `docs/architecture/adr/`에 기록한다.
